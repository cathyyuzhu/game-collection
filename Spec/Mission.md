# Game Collection · Mission（项目使命与总览）

## 1. 一句话简介
> 面向全球手游玩家的多语言（简中/繁中/英文）游戏排行榜与攻略聚合站，通过 SEO 吸引搜索流量，以内容聚合 + LLM 二次加工模式提供结构化、时效清晰的游戏信息，远期通过广告变现。

## 2. 愿景与使命
- **愿景（Vision）：** 成为手游玩家搜索攻略和找新游戏时的首选中文/英文信息入口。
- **使命（Mission）：**
  1. 聚合 iOS + Android 双平台的热门游戏榜单，提供可信、透明、可对比的排行榜。
  2. 为每款热门游戏产出结构化、标注适用版本的高质量攻略（多语言）。
  3. 以干净、无广告的前期体验积累用户口碑和搜索引擎权重。

## 3. 目标用户（TA）
- **主要用户群体（60%）：** 中文手游玩家（大陆 + 港澳台 + 东南亚华人）
  - 典型画像：20-35 岁，每天玩手游 1-3 小时，遇事习惯百度/Google 搜「XX 攻略」「XX 怎么配队」
  - 典型场景：卡关了搜 Boss 打法；想抽卡前搜「值不值得抽」；找新游戏时搜「202X 好玩手游推荐」
- **次要用户群体（30%）：** 英语系手游玩家（北美、东南亚、印度）
  - 典型画像：喜欢玩 Gacha / RPG / 策略类手游，查英文攻略和 Tier List
- **边缘用户群体（10%）：** 想出海/了解海外手游市场的开发者/发行商
- **用户痛点：**
  1. 传统游戏媒体广告多、内容水、攻略过时不标版本号
  2. 单款游戏的攻略散落在论坛、贴吧、TapTap 社区，信息碎片化
  3. iOS 和安卓的榜单分散，想一站式看全平台热门很难
  4. 英文攻略和中文攻略割裂，同一款游戏的信息对不上

## 4. 核心价值主张（Value Proposition）
为什么用户要选择这个项目 / 产品？与现有方案相比的差异化：

| 差异化点 | 具体做法 | 现有竞品的问题 |
|----------|----------|----------------|
| 🧭 **结构化攻略** | 强制步骤编号、TL;DR 摘要、关键数值表格化，用户 30 秒拿到答案 | 传统站长篇大论，翻 5 分钟才找到重点 |
| 🏷️ **适用版本标签** | 每篇攻略强制标注「适用游戏版本号」和「最后更新时间」 | 90% 的攻略站不标版本，游戏大更后攻略完全过时还排在搜索结果前列 |
| 🌐 **三语同源** | 同一篇攻略的简中/繁中/英文内容是同一条数据源生成的，信息完全一致，支持一键切换 | 英文站和中文站是两套独立内容，信息对不上 |
| 🏆 **多平台综合排行榜** | iOS + 安卓加权热度，同时展示 TapTap 评分 / App Store 评分 / 下载量估算 | 大多数站只展示单平台榜单，没有综合排名 |
| 🧼 **干净无广告（前期）** | V1 不接入任何广告，纯展示内容 | 传统站弹窗/插屏/悬浮广告满天飞，阅读体验极差 |

## 5. 项目范围（In / Out of Scope）
- ✅ **本项目 V1 做什么：**
  - iOS + Android 双平台手游的 Top 100 热门游戏
  - 每款游戏覆盖 5 篇精选攻略（新手入门、核心玩法/配队、Boss/关卡、抽卡建议、常见问题）
  - 三语内容：简体中文（zh-CN）、繁体中文（zh-TW）、英文（en）
  - 首页综合排行榜 + 分类排行榜
  - 游戏详情页 + 攻略详情页
  - 站内搜索
  - 完整 SEO 基建（sitemap、robots、Schema.org、hreflang）
  - 内容生产流水线（爬虫 → LLM 抽取 → 改写 → 翻译 → 质检 → 发布）

- ❌ **本项目 V1 不做什么（V2 再评估）：**
  - Steam / PC / 主机平台的游戏
  - 用户注册、登录、评论、发帖等 UGC 系统
  - 广告投放（日 UV 过万后再接入）
  - 移动端 App
  - 付费会员 / 付费墙
  - 数据分析看板（前期用 Google Analytics 免费版 + Search Console）

## 6. 成功指标（Success Metrics）
### 6.1 内容指标（上线 1 个月内）
- [ ] 游戏库覆盖：≥ 100 款热门手游（iOS + 安卓 Top 榜单重合度 ≥ 60%）
- [ ] 攻略数量：≥ 500 篇终稿（每款游戏 ≥ 5 篇），三语齐全
- [ ] 内容质量：人工抽检通过率 ≥ 90%（无事实错误、格式正确、版本标签齐全）
- [ ] 原创性检测：和原始采集源的文本重复度 ≤ 30%

### 6.2 SEO/流量指标（上线 3 个月）
- [ ] 搜索引擎收录量：Google ≥ 1000 页，百度 ≥ 500 页
- [ ] 核心关键词排名：Top 20 关键词 ≥ 50 个（「XX 攻略」「XX  tier list」类）
- [ ] 日独立访客（UV）：≥ 500（来自自然搜索的比例 ≥ 70%）
- [ ] 页面平均停留时间：≥ 2 分钟（攻略详情页）

### 6.3 流量指标（上线 6 个月，广告变现门槛）
- [ ] 日 UV ≥ 5000
- [ ] 月页面浏览量（PV）≥ 30 万
- [ ] 跳出率 ≤ 60%

### 6.4 远期指标（上线 12 个月）
- [ ] 日 UV ≥ 5 万
- [ ] 广告月收入 ≥ ¥10,000（或等价 USD）
- [ ] 游戏库扩充至 ≥ 500 款

## 7. 约束与假设
### 已知约束
- **合规约束：** 内容来源为「多源采集 + LLM 二次加工」，需确保文本重复度 < 30%，关键图片不得直接盗用原创者版权作品
- **模型约束：** 主力 LLM 使用 DeepSeek 系列（V2 / V2-Lite），需提前充值并获得正式 API Key，预留 QPS ≥ 20
- **预算约束（V1）：** 服务器 + API + 第三方服务，月成本控制在 ¥500 以内
- **搜索约束：** 新站前 3 个月 SEO 效果有限，需接受冷启动期无收入

### 关键假设
1. **需求假设：** 「手游攻略 + 排行榜」的搜索需求持续存在，且现有搜索结果的满意度不高（广告多、过时、不结构化）
2. **质量假设：** DeepSeek V2 的中文改写质量 + V2-Lite 的抽取质量，足以支撑「人工抽检通过率 ≥ 90%」
3. **流量假设：** 500 篇三语结构化攻略 + 完整 SEO 基建，6 个月内可以通过自然搜索达到日 UV 5000+
4. **成本假设：** 三语 500 篇攻略的 LLM + DeepL API 总成本 ≤ ¥100
